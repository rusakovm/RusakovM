### 🏢 Information System — автоматизированная информационная система

**C# · Windows Forms · .NET Framework 4.7.2 · Microsoft SQL Server**

Дипломный проект — настольная информационная система, разработанная для автоматизации учёта и обработки данных в сфере газораспределения.

**Реализованные возможности:**
- Учёт сотрудников и управление их данными.
- Формирование рабочих графиков и расписаний.
- Учёт заработной платы.
- Регистрация потребителей и приборов учёта газа.
- Внесение и обработка показаний счётчиков.
- Расчёт начислений и работа с квитанциями.
- Управление заявками на обслуживание.
- Разграничение прав доступа пользователей.
- Формирование PDF-документов и работа с QR-кодами.

**Что демонстрирует:** проектирование реляционной базы данных, использование SQL-запросов, разработку графического интерфейса на Windows Forms, организацию бизнес-логики и взаимодействие приложения с Microsoft SQL Server.

Проект разработан в рамках дипломной работы. Представляет собой учебный прототип информационной системы, а не официально внедрённое программное обеспечение организации.

[📂 Исходный код и скриншоты](https://github.com/rusakovm/Information-System)

### 🤖 Local AI Voice Assistant — локальный голосовой ИИ-ассистент

**C# · .NET · Ollama · Vosk · Piper · NAudio**

Экспериментальный голосовой ассистент с модульной архитектурой и локальной обработкой запросов.

**Реализованные компоненты:**
- Распознавание речи с помощью Vosk.
- Генерация текста через Ollama и Llama 3.1.
- Синтез речи через Piper.
- Обмен сообщениями между процессами через Named Pipes.
- Потоковая генерация ответов.
- Управление историей диалога.
- Прерывание воспроизведения при новом запросе.

**Что демонстрирует:** межпроцессное взаимодействие, асинхронную обработку, HTTP API и интеграцию ИИ-моделей.

[📂 Исходный код](https://github.com/rusakovm/Local-AI-Voice-Assistant)
