### 🧪 проекты — TestSystem

**TestSystem** — веб-приложение для управления процессом тестирования компьютерного оборудования.

**Реализованные возможности:**
- Учёт устройств и моделей
- Настройка фаз и планов тестирования
- Проведение тестовых сессий
- Сохранение результатов проверок
- История тестирования
- Авторизация пользователей

**Стек:** Python, Django, SQLite, HTML, CSS, JavaScript.
